# DIGNN 长程/全局增强模块：方法、效果与使用指南

> 本文档面向论文写作与正式训练配置。系统性说明在 DIGNN（局部高阶几何 GNN）之上新增的
> 四个长程/全局增强组件的**机制、公式、消融效果、局限性与推荐参数**。
> 所有实测数据来自 JARVIS（晶体，1000 冒烟样本）与 QM7（分子，1000 样本）的多 seed 消融。

---

## 0. 总体定位

DIGNN 采用「编码 → 解构(短程高阶几何 HGC) → 整合(长程交互 LCP) → 解码」架构，
其核心归纳偏置是**局部几何**，在多数强度量性质上已达 SOTA，但对**能量类长程依赖性质**
（总能量、形成能）表现不足——根因是局部消息传递无法捕捉长程相互作用（静电尾部、色散）。

本工作的定位是 **「局部高阶几何 GNN + 轻量全局补充」**，即在不改动局部主线的前提下，
以**可开关、可退化、O(N)、保持平移/PBC 不变性与能量-力可导性**的方式补充全局/长程信息。
共实现四个组件（均默认关闭，不影响既有实验）：

| 组件 | 层级 | 位置 | 作用 |
|---|---|---|---|
| Global Virtual Node | 特征级（mean-field 全局） | Processor/LCP | 缓解 oversquashing，补全局上下文 |
| Phase token (iso) | 特征级（距离感知） | Processor/LCP | 各向同性傅里叶相位，补距离感 |
| Phase token (recip) | 特征级（距离感知） | Processor/LCP | 倒格矢傅里叶相位，晶体专用 |
| LES (Latent Ewald) | 能量级（物理项） | Decoder | 潜电荷倒空间静电能 |

## 1. Global Virtual Node（全局虚拟节点）

### 1.1 机制
在基于局部消息传递的 GNN 中引入虚拟节点补充全局信息。实现为
[`GlobalInteraction`](../nn/models/modules/processor_components.py)，采用**多 token 注意力池化 → 广播**：

- 每个 virtual token 拥有独立可学习 query 与 value 变换；
- 对每个 token，按图内原子做注意力打分 → softmax（严格按 `atom_batch` 隔离，防跨图泄漏）→
  加权池化得每图每 token 的全局向量；
- 全局向量广播回各原子，与原子特征拼接后经 MLP 得到更新量；
- 以 ReZero/LayerScale 门控残差注入：`h ← h + gate · norm(Δ)`，`gate` 初值 0.1。

### 1.2 关键设计
- **多 token 而非单一 mean**：每个 token 关注不同原子子集（类似 Set Transformer 的 PMA），
  避免多 token 信息趋同；`num_tokens=1` 时退化为单个学习加权池化。
- **无显式边、无自由 vnode 参数**：vnode 每层由全图特征当场聚合，是数据驱动的全局摘要。
- **仅用标量特征、不涉坐标** → 平移/旋转不变，不破坏能量-力导数关系，复杂度 O(N)，兼容 PBC。
- **门控初值取小正数 0.1（LayerScale 式）而非纯 ReZero 的 0**：0 会压制模块自身梯度导致
  欠训练；小正值既保初始扰动小（稳定）又避免梯度被压死（保收敛）。

### 1.3 效果（多 seed 实测）
- **JARVIS 晶体：val_mae 均值 −8.0%，3 seed 极稳（std<0.001）** —— 唯一在两个数据集都不掉链子的模块。
- QM7 分子：−0.8%（持平，std 极小），无害。

### 1.4 局限
- 提供的是 mean-field 式全局上下文，**不含真实两两距离**（这是 Phase token 补的）。
- 分子体系收益有限（分子本身长程效应弱、体系小）。

## 2. Phase token — 傅里叶相位增强（各向同性 iso）

### 2.1 动机
Global vnode 是「位置盲」的均值摘要。RANGE（Nat. Commun. 2026）用粗糙的质心相对位置编入 edge，
仍是代理。我们改为在注意力聚合时引入**真实傅里叶相位**，使全局摘要携带空间频率信息，
逐原子获得**基于真实两两距离**的长程感知。

### 2.2 公式（全实数实现，避免复数 autograd）
设注意力权重 `α_i`、相位值变换 `z_i = phase_value(h_i)`，对每个固定波矢 `k`：

```
C_k = Σ_i α_i · z_i · cos(k·r_i)      （按 atom_batch 隔离聚合）
D_k = Σ_i α_i · z_i · sin(k·r_i)
g_phase_{j,k} = C_k[b_j]·cos(k·r_j) + D_k[b_j]·sin(k·r_j)
              = Σ_i α_i · z_i · cos(k·(r_i − r_j))
```

「减自身相位」使结果只依赖相对位置 `r_i − r_j`：**平移严格不变，精确包含真实两两距离**
（优于取模 |S(k)| 的单一图级摘要——后者广播后每个原子相同，仍是 mean-field 味）。

### 2.3 k 向量（iso）
`_build_isotropic_k`：波长在 [λ_min, λ_max]=[3,15]Å 对数均匀取样 → |k|=2π/λ；
方向用黄金螺旋在单位球面均匀铺点。注册为 **buffer（不可学习）**——k 是物理量纲、跨分布不变，
不增加过拟合面，契合小样本/OOD。默认 `n_k=4`。

### 2.4 两级门控与拼接式融合
- 相位通道以**拼接**方式接入 update 的 MLP（`dim·(1+num_tokens) → dim·(1+num_tokens+num_tokens·n_k)`），
  **不替代**原 mean-field 通道；
- 内层 `gate_phi`（默认 0.2）缩放相位路，`gate_phi=0` 时该路输出恒 0 → **严格退化**到 mean-field，
  表达力只增不减；外层 ReZero gate 控整体注入。两级门控相乘会双重压制梯度，故 gate_phi 初值取略大（0.2~0.3）。

### 2.5 效果与局限
- **旋转不变性只是近似**：有限个固定 k 方向不随坐标旋转，精确不变需 k 在球壳密集覆盖。须如实标注。
- 各向同性 k 对晶体存在 **minimum-image 歧义**（跨原胞相对相位未定义）——这正是 recip 版要解决的。
- 实测：见下节与第 5 节汇总。**分子上 iso 版反而有害（+6.3%）**，晶体上需用 recip 版。

## 3. Phase token — 倒格矢版（reciprocal，晶体专用）

### 3.1 机制
晶体的长程结构由**倒格矢**张成。用每图的倒格矢生成 k，使 `exp(ik·r)` 对晶格平移**严格周期**，
从物理上消除固定各向同性 k 的 minimum-image 歧义。

```
A = cell（行向量为晶格矢 a1,a2,a3）
B = 2π (A⁻¹)ᵀ            # 倒格矢基，满足 b_i·a_j = 2π·δ_ij
k = n · B                # n 为密勒指数（整数组合）
```

密勒指数由 `_build_miller(n_max)` 生成：保留 `0<|n|²≤n_max²` 且去除 ±n 冗余（|S(k)|²=|S(−k)|²）。
数量：`n_max=1→3 个 k`，`n_max=2→16 个 k`，`n_max=3→61 个 k`。
分子体系（无 cell）自动**回退**到各向同性 k。

### 3.2 效果（JARVIS 晶体，公平对照 —— 本工作最关键的实验）
> ⚠️ 必须**控制 k 数量/参数量对齐**才能公平比较 iso vs recip。
> 早期用 iso(n_k=4,63k) 对比 recip(n_max=2→16个k,112k) 是**缺陷对照**（参数差近 2 倍），
> 会误得「iso 更好、recip 过拟合」的错误结论。

| 对齐组 | 配置 | 参数量 | val_mae 均值±std | 结论 |
|---|---|---|---|---|
| A (k=3) | phase(recip, n_max=1) | 59k | **0.3910 ± 0.022** | **倒格矢胜 8.5%（3 seed 一致）** |
| A (k=3) | phase(iso, n_k=3) | 59k | 0.4272 ± 0.018 | |
| B (k=16) | phase(recip, n_max=2) | 112k | 0.3999 ± 0.010 | 与 iso 持平 |
| B (k=16) | phase(iso, n_k=16) | 112k | 0.4002 ± 0.014 | |

**核心洞察**：倒格矢用**仅 3 个 k** 即达到甚至略超各向同性用 16 个 k 的效果
（recip-k3 0.391 ≈ recip-k16 0.400）——**更省参数反而更好**。物理正确的归纳偏置
（晶格平移严格不变）让小容量拿到好结果，印证「容量是负债」。晶体长程结构本由倒格矢张成，
iso 只能盲猜方向、需堆数量。

### 3.3 局限
- **仅晶体有效**：分子无周期性，回退 iso；而分子上 iso 版无益（见第 4 节 QM7）。
- 仍为特征级增强，非严格 Ewald 能量。
- 数值验证已确认：晶格平移不变（误差 6e-8）、整体平移不变、二阶导可回传、gate_phi=0 严格退化。

## 4. LES（Latent Ewald Summation，潜 Ewald 长程能量项）

### 4.1 机制（Decoder 内，能量级物理项）
参考 Bingqing Cheng (npj Comput Mater 2025)。每原子学一个**标量潜电荷** `w_i=Linear(h_i)`
（无需真实电荷标签），构建倒空间静电能：

```
S(k) = Σ_i w_i · exp(ik·r_i)                    # 结构因子（cos/sin 双路实数实现）
E_lr = Σ_k f(|k|) · |S(k)|²,  f(|k|)=exp(−σ²|k|²/2)/|k|²   # Ewald 倒空间核
```

- **电荷中性软约束**：每图减去均值电荷（Σw_i=0），规避 |S(k→0)| 发散；
- **广延量适配**：E_lr 是 extensive。若 label 为每原子能量（mean pool），E_lr 除以图原子数保量纲；
  若为总能量（sum pool），天然匹配、直接相加；
- **门控退化**：`les_gate` 初值 0 严格退化；可调大（如 0.5）在短训练内强制打开。
- 数据流复用 pos/cell；晶体可用倒格矢 k（`les_use_reciprocal`）。

### 4.2 效果 —— **两个数据集均证伪，路线放弃**
| 数据集 | 配置 | val_mae 均值±std | vs baseline |
|---|---|---|---|
| JARVIS(晶体,mean) | LES(iso, gate0.5) | 0.531 ± 0.042 | +19.3% |
| JARVIS(晶体,mean) | LES(recip, gate0.5) | 0.501 ± 0.033 | +12.6% |
| **QM7(分子,sum，LES 主场)** | LES(gate0) | **18.09 ± 16.8**（seed123 发散到 41.6） | +286% |
| QM7(分子,sum) | LES(gate0.5) | 5.62 ± 0.35 | +19.9% |

> QM7 是**为 LES 精心准备的主场**（分子 + 总能量 extensive + sum pooling + 无需除 N），
> LES 依然失败甚至发散——**说明问题是机制本身，而非数据不公平**。

### 4.3 失败根因（论文可作为负结果讨论）
1. **潜电荷欠约束**：w_i 是从能量反推的自由变量、无标签监督。原论文靠**大数据 + 力监督 + 长训练**
   才让潜电荷收敛；本场景（千级样本、30 epoch、仅能量无力）下 w_i 学成噪声。
2. **二次型放大不稳定**：`|S(k)|²` 是电荷的二次型，w_i 的微小抖动被平方放大，小数据下极易发散
   （QM7 seed123 = 41.6 是直接证据）。

### 4.4 结论
在**小数据 + 无力监督**场景，LES 不适配，应放弃。若未来在**大数据 + 含力标签**的力场训练中，
可重新评估（那是原论文的成立条件）。

## 5. 跨数据集整合结论

| 模块 | JARVIS(晶体) | QM7(分子) | 判定 |
|---|---|---|---|
| **+global** | −8.0% ✓ | −0.8% ≈ | **稳健通用，推荐默认开启** |
| **phase(recip)** | −8.5%（k=3 公平对照）✓ | 不适用（回退 iso） | **晶体专用，推荐** |
| phase(iso) | 一般（劣于 recip） | +6.3% ✗ | 不推荐单独用 |
| **LES** | 证伪(+12~19%) | 主场仍证伪+发散 | **放弃（小数据无力监督下）** |

**额外洞察**：phase 晶体有效、分子有害，**反向印证 phase 的增益来自晶体周期性/倒格矢结构**，
与「倒格矢 > 各向同性」结论自洽。

## 6. 正式训练推荐配置（大数据集）

### 6.1 晶体任务（如 JARVIS 总能量/形成能）
```python
# Processor
use_global_token=True, num_global_tokens=2,
use_phase=True, phase_use_reciprocal=True, phase_n_max=1,   # k=3 倒格矢，性价比最佳
# gate_init=0.1（默认），gate_phi_init=0.2（默认）
# Decoder
use_les=False                                               # LES 不采用
```
- **首选**：`global + phase(recip, n_max=1)`（k=3，最省参数、最稳）。
- **大数据可试**：`phase_n_max=2`（k=16）——冒烟规模上与 n_max=1 持平，但完整几万样本 +
  更强正则下，更多倒格矢或能进一步发挥，值得作为对照。
- `num_global_tokens`：2 起步；体系更大/更复杂可试 4。

### 6.2 分子任务（如 QM7/MD 力场）
```python
use_global_token=True, num_global_tokens=2,
use_phase=False,        # 分子上 phase(iso) 无益
use_les=False,
```
- 分子只推荐 `+global`。phase/LES 均不建议。

### 6.3 通用超参（沿用消融设置，供参考）
- k 波长覆盖 `lam_min=3, lam_max=15`（Å）；k 均为固定 buffer、不可学习。
- 门控：`gate_init=0.1`（外层 LayerScale），`gate_phi_init=0.2`（内层相位）。
- 训练：AdamW + OneCycle；本轮消融用 lr=1e-3、30 epoch、batch 视显存而定。

### 6.4 重要提醒
- 以上结论基于 **1000 样本冒烟 + 小模型 + 30 epoch**，趋势可信但绝对数值有噪声。
  正式训练请在完整数据上**复核 phase(recip, n_max=1 vs 2)** 与 **global 的 token 数**。
- 能量任务务必确认 label 是「每原子」还是「总量」，对应 `pooling='mean'/'sum'`，
  否则 size-consistency 会出系统偏差。

## 8. 进一步建议（可完善方向）

1. **完整数据复核**：冒烟结论需在几万样本上验证，尤其 phase(recip) n_max=1 vs 2、global token 数。
2. **力场场景重评 LES**：LES 的失败绑定「小数据+无力监督」。若做力场训练（有力标签、大数据），
   值得单独重测——那才是原论文的成立条件。
3. **phase(recip) 的旋转等变性**：当前是近似旋转不变；若追求严格性，可考虑对倒格矢做对称化平均。
4. **OOD 评估**：项目未来以小样本/OOD 为主，建议补 OOD 划分下的 phase(recip) vs baseline 对比，
   验证物理先验的外推收益（理论上倒格矢的物理正确性在 OOD 更占优）。
5. **可解释性探针**：可对 gate_phi / les_gate 的训练轨迹与 virtual token 注意力做 SVD 分析，
   佐证「相位通道确实被使用」及「全局信息为 N-body」。
